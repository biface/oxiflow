Expand description

Abstract spatial mesh — INV-1 invariant.

All spatial information consumed by the engine passes through this trait. No implementation detail (dx, nx, node table) leaks into the public API.

§Object safety

This trait is object-safe: it can be used as Box<dyn Mesh> and &dyn Mesh. Required for INV-4 (plugin-safe API, v0.30.0 / J30, DA-017).

§Implementing Mesh

A minimal implementation for a 1D uniform grid:

use oxiflow::mesh::Mesh;

struct MyGrid { n: usize, dx: f64 }

impl Mesh for MyGrid {
    fn n_dof(&self) -> usize { self.n }
    fn coordinates(&self, i: usize) -> &[f64] {
        // In practice, return a slice into a pre-computed node table.
        // This example uses a workaround for illustration only.
        std::slice::from_ref(Box::leak(Box::new(i as f64 * self.dx)))
    }
    fn spatial_dimension(&self) -> usize { 1 }
    fn characteristic_length(&self) -> f64 { self.dx }
}

§INV-1 compliance

Implementations must not expose dx, nx or raw indices in any public method beyond those defined here. Spatial parameters are internal details.

Required Methods§

fn n_dof(&self) -> usize

Total number of degrees of freedom (nodes) in the mesh.

For a 1D uniform grid: n_dof() == n_points. For a 2D FEM mesh: n_dof() is the number of mesh nodes.

Source

fn coordinates(&self, i: usize) -> &[f64]

Coordinates of node i as a slice of length spatial_dimension().

Returns &[f64] — zero allocation. Callers must not store the returned reference beyond the lifetime of the mesh. Implementors typically return a slice into a pre-computed node coordinate table.

§Panics

Implementations may panic if i >= n_dof(). Use n_dof() to guard iteration bounds.

Source

fn spatial_dimension(&self) -> usize

Number of spatial dimensions of this mesh.

  • 1 for 1D grids (chromatography column, 1D heat transfer)
  • 2 for 2D meshes (surface flow, 2D diffusion)
  • 3 for 3D meshes (volumetric FEM)
Source

fn characteristic_length(&self) -> f64

A representative spatial length scale of the mesh.

Used by integrators and operators for stability estimates (CFL condition, Péclet number). For a uniform 1D grid: dx. For unstructured meshes: the minimum element diameter or average edge length.

fn boundary_nodes( &self, region: &BoundaryRegion, ) -> Result<Vec<usize>, OxiflowError>

Nodes of the boundary region (DA-071).

The default implementation covers the two faces of a 1D mesh, normal to axis 0, assuming nodes ordered along the axis: Lower is node 0, Upper node n_dof() − 1. Meshes of higher dimension, or whose nodes are not in that order, override it.

§Errors

OxiflowError::PreconditionFailed for a region the mesh does not define (with the default: another axis, a mesh that is not 1D) or a mesh without nodes.

Source

fn boundary_neighbours( &self, region: &BoundaryRegion, ) -> Result<Vec<BoundaryNode>, OxiflowError>

Nodes of the boundary region, each with its first neighbour along the inward normal and their distance (DA-071) — what a condition written on a structured grid needs, such as a one-sided difference across the boundary.

The default implementation covers the two faces of a 1D mesh, normal to axis 0, assuming nodes ordered along the axis: Lower is node 0 with neighbour 1, Upper node n_dof() − 1 with neighbour n_dof() − 2. Only the order of that boundary pair is checked (its distance must be positive), not the order of the whole mesh.

Unstructured meshes have no such neighbour: they keep a refusal here, a condition on them being imposed weakly instead.

§Errors

OxiflowError::PreconditionFailed for a region the mesh does not define, a mesh with fewer than two nodes, or a boundary pair whose distance is not positive (nodes not ordered along the axis).

impl<M: Mesh + ?Sized> Mesh for Arc<M>

A mesh behind an Arc is a mesh: one grid, built once, can then serve a component that holds an Arc (a flux scheme, a calculator) and a Domain, which owns a Box<dyn Mesh>, without being copied or built twice.

Every method forwards to the shared mesh, including those with a default implementation, so that a mesh which overrides them keeps its own answers.

§Examples

use std::sync::Arc;
use oxiflow::mesh::{Mesh, UniformGrid1D};

let grid = Arc::new(UniformGrid1D::new(5, 0.0, 1.0)?);
let owned: Box<dyn Mesh> = Box::new(Arc::clone(&grid));
assert_eq!(owned.n_dof(), grid.n_dof());
assert_eq!(Arc::strong_count(&grid), 2);
