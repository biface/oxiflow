Expand description

Computes one context variable and injects it into ComputeContext.

The solver calls calculators in topological order — a calculator that depends_on() variable X is guaranteed to run after the calculator that provides() X. Within a dependency tier, execution order is determined by priority() (inherited from RequiresContext).

§Contract

  • provides() must return a stable ContextVariable — the same value across calls for a given calculator instance.
  • compute() receives the current field state and a partially populated ComputeContext (variables with lower priority already resolved).
  • compute() must not modify ctx directly — the solver inserts the result.
  • The solver calls compute_shared(), which defaults to compute(). A calculator that keeps its value between evaluations overrides it to hand that value over without a copy (DT-068).

§DiscreteOperator (INV-2, J5)

Spatial calculators (gradient, Laplacian, flux) may internally hold a DiscreteOperator implementation. This is an implementation detail of the calculator — DiscreteOperator is never exposed in SolverConfiguration.

§Examples

use oxiflow::context::calculator::ContextCalculator;
use oxiflow::context::variable::ContextVariable;
use oxiflow::context::value::ContextValue;
use oxiflow::context::compute::ComputeContext;
use oxiflow::context::error::OxiflowError;
use oxiflow::model::traits::RequiresContext;

#[derive(Debug)]
struct TimeCalculator;

impl RequiresContext for TimeCalculator {
    fn required_variables(&self) -> Vec<ContextVariable> { vec![] }
    fn priority(&self) -> u32 { 0 }
}

impl ContextCalculator for TimeCalculator {
    fn provides(&self) -> ContextVariable { ContextVariable::Time }
    fn compute(&self, _state: &ContextValue, ctx: &ComputeContext)
        -> Result<ContextValue, OxiflowError>
    {
        Ok(ContextValue::Scalar(ctx.time()))
    }
    fn name(&self) -> &str { "time" }
}

Variables declared in depends_on() are guaranteed to be present in ctx when this method is called.

fn compute_shared( &self, state: &ContextValue, ctx: &ComputeContext, ) -> Result<Arc<ContextValue>, OxiflowError>

Computes the value for provides() as a shared allocation.

This is the method the solver calls at each derivative evaluation. The default wraps the result of compute() in an Arc: the value is moved, not copied, at the cost of one Arc allocation per evaluation.

§When to override

Override it when the calculator keeps a value from one evaluation to the next (for instance a coefficient field evaluated once on the mesh). Returning a clone of the kept Arc hands over the same allocation to every evaluation, where compute() would have to copy the whole value.

§Contract

An override returns the same value as compute() for the same state and ctx. compute() stays required, and remains the method to call outside the solver.

This method is not a parallel-dispatch capability and carries no configuration, so it is consistent with P3 of DA-048: an implementer that ignores it is unaffected.

§Examples
use std::sync::Arc;

use nalgebra::DVector;
use oxiflow::context::{
    ComputeContext, ContextCalculator, ContextValue, ContextVariable, OxiflowError,
};
use oxiflow::model::RequiresContext;

/// Coefficient field evaluated once, then shared with every evaluation.
#[derive(Debug)]
struct FixedCoefficient {
    field: Arc<ContextValue>,
}

impl RequiresContext for FixedCoefficient {
    fn required_variables(&self) -> Vec<ContextVariable> { vec![] }
}

impl ContextCalculator for FixedCoefficient {
    fn provides(&self) -> ContextVariable {
        ContextVariable::External { name: "c".into() }
    }
    fn compute(&self, _state: &ContextValue, _ctx: &ComputeContext)
        -> Result<ContextValue, OxiflowError>
    {
        Ok(self.field.as_ref().clone())
    }
    fn compute_shared(&self, _state: &ContextValue, _ctx: &ComputeContext)
        -> Result<Arc<ContextValue>, OxiflowError>
    {
        Ok(Arc::clone(&self.field))
    }
}

let calc = FixedCoefficient {
    field: Arc::new(ContextValue::ScalarField(DVector::from_element(5, 0.5))),
};
let state = ContextValue::ScalarField(DVector::zeros(5));
let ctx = ComputeContext::new(0.0, 0.01);

let first = calc.compute_shared(&state, &ctx)?;
let second = calc.compute_shared(&state, &ctx)?;
assert!(Arc::ptr_eq(&first, &second));
assert_eq!(*first, calc.compute(&state, &ctx)?);
