§Module model::initial_condition

PrescribedInitialState — any PhysicalModel started from a given state instead of its own initial condition.

§Why

A model’s PhysicalModel::initial_state is fixed by the model itself. Two situations need another starting point without changing the model:

  1. Resuming a run from a SimulationSnapshot: the restore contract of DT-025 leaves it to the caller to rebuild the scenario and re-inject the saved state as the initial condition. Wrapping the model is that re-injection; Scenario::with_t_start sets the matching start time.
  2. Starting from a state computed elsewhere: a developed flow, a perturbed equilibrium, the end state of another run.

The wrapper changes the initial condition and nothing else: every other RequiresContext and PhysicalModel method is delegated, name() included, so the result of a run keeps the wrapped model’s name.

§What a resume reproduces

A run resumed at step N from a snapshot and continued for M steps matches an uninterrupted N + M run under two conditions:

  • One-step integrators only. A snapshot carries no history, so a multistep integrator (BDF2) restarts on its bootstrap step and the two runs part from there.
  • Times agree to rounding, not bit for bit. The fixed-step loop computes each time as t_start + k·dt. Resumed from t_start = t_N, it computes t_N + k·dt where the uninterrupted run computes (N + k)·dt; the two can differ in the last bits. States are identical for a model that does not read the time; a model that does sees those last-bit differences.

§Shape

initial_state cannot report an error, so the prescribed state is checked against the mesh by Scenario::validate, which Solver::solve and the orchestrator call before the first step. A caller that drives SteppableSolver::step in its own loop calls it itself.

§Examples

Resuming a run from a snapshot taken at t = 0.5:

use nalgebra::DVector;
use oxiflow::context::{ComputeContext, ContextValue, ContextVariable, OxiflowError};
use oxiflow::mesh::{Mesh, UniformGrid1D};
use oxiflow::model::{PhysicalModel, PrescribedInitialState, RequiresContext};
use oxiflow::solver::config::{IntegratorKind, StepControl, TimeConfiguration};
use oxiflow::solver::methods::ForwardEulerSolver;
use oxiflow::solver::scenario::Scenario;
use oxiflow::solver::snapshot::SimulationSnapshot;
use oxiflow::solver::{Solver, SolverConfiguration};

struct Decay;
impl RequiresContext for Decay {
    fn required_variables(&self) -> Vec<ContextVariable> { vec![] }
}
impl PhysicalModel for Decay {
    fn compute_physics(&self, s: &ContextValue, _: &ComputeContext)
        -> Result<ContextValue, OxiflowError> {
        Ok(ContextValue::ScalarField(s.as_scalar_field()?.map(|v| -v)))
    }
    fn initial_state(&self, mesh: &dyn Mesh) -> ContextValue {
        ContextValue::ScalarField(DVector::from_element(mesh.n_dof(), 1.0))
    }
    fn name(&self) -> &str { "decay" }
}

let time = TimeConfiguration::new(0.5, StepControl::Fixed { dt: 0.125 });
let first = Scenario::single(Box::new(Decay), Box::new(UniformGrid1D::new(4, 0.0, 1.0)?));
let run = ForwardEulerSolver.solve(&first, &SolverConfiguration::new(time.clone(), IntegratorKind::Euler))?;

// Explicit checkpoint at the end of the first run.
let snapshot = SimulationSnapshot {
    time_config: time,
    integrator: IntegratorKind::Euler,
    state: run.states.last().unwrap().clone(),
    t: run.t_final().unwrap(),
    n_steps: run.n_steps,
    error: None,
    partial: None,
};

// Rebuild the scenario, re-inject the state, restart from its time.
let model = PrescribedInitialState::new(Box::new(Decay), snapshot.state.clone());
let resumed = Scenario::single(Box::new(model), Box::new(UniformGrid1D::new(4, 0.0, 1.0)?))
    .with_t_start(snapshot.t);
let config = SolverConfiguration::new(
    TimeConfiguration::new(1.0, StepControl::Fixed { dt: 0.125 }),
    IntegratorKind::Euler,
);
let rest = ForwardEulerSolver.solve(&resumed, &config)?;
assert_eq!(rest.states[0], snapshot.state);
assert_eq!(rest.t_final(), Some(1.0));
