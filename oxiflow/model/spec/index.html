§Module model::spec

External, serialisable description of a physical model and of its initial state — the model part of the WHAT-axis configuration (DT-027 amendment 1, #108).

ModelSpec describes the model of a domain; InitialStateSpec the state it starts from, when it is not the model’s own. Both are consumed by DomainSpec, which holds the mesh they are built on.

Only the models built from public components are covered: a DiscretizedModel over one of the flux schemes of operators. CompositeModel is left out of this first increment, since no public source term exists to compose with a flux; physical models defined outside the crate cannot be described (DD-072).
