§Module boundary::spec

External, serialisable description of boundary conditions — the boundary part of the WHAT-axis configuration (DT-027 amendment 1, #108).

BoundaryConditionSpec names one of the conditions of this module and its parameters; TimeFunctionSpec describes a value that depends on time. Both are consumed by DomainSpec.

A function of time held as a Rust closure, as Dirichlet::of_t takes, has no serialisable form: its type gives its signature, not the function. TimeFunctionSpec describes the function instead (a constant, a parametric profile, or a tabulated series), and the closure is rebuilt from that description when the domain is built. Closed-form expressions of time are planned by DD-072.
