pub fn dirac_initial_state(n_dof: usize, amount: f64) -> DVector<f64>
Expand description

Builds a Dirac-like initial condition: all amount concentrated at the first node, zero elsewhere — the injected mass is already inside the domain at t = 0, rather than delivered as a boundary event over time. See the module documentation for why this crate treats Dirac differently from chrom-rs (a boundary-flux impulse there).

Returns a zero vector unchanged if n_dof == 0.
