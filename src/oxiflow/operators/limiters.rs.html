1//! # Module `operators::limiters`
2//!
3//! Flux-limited (MUSCL-style) advective flux + centered diffusive flux for
4//! [`UniformGrid1D`] — [`Limiter`] (`MinMod`, `VanLeer`, `Superbee`) and
5//! [`LimitedFlux`] (#99, split out of `#49` at closing time — DD-012,
6//! DD-039, DD-041).
7//!
8//! ## Why a limiter, alongside FV and WENO
9//!
10//! `operators::fv::FVUpwindFlux` is 1st order (diffusive on sharp fronts);
11//! `operators::fv::FVCenteredFlux` and `operators::weno` are higher order
12//! but need a smoothness-driven blend (WENO's nonlinear weights) or, here, a
13//! slope limiter to stay non-oscillatory near a discontinuity while
14//! recovering 2nd order where the solution is smooth. A limiter is
15//! considerably cheaper than WENO's multi-substencil reconstruction —
16//! useful on its own for advection-dominated regions where WENO's extra
17//! cost buys little, and as the "steep" half of the adaptive WENO/limiter
18//! blend (a separate, not-yet-designed piece of work — see the tracking
19//! note at the end of this doc).
20//!
21//! ## MUSCL reconstruction, not a flux blend
22//!
23//! Two equivalent formulations exist in the literature: blending a low- and
24//! a high-order *flux* with `φ(r)` (Sweby, 1984), or directly building a
25//! limited-slope *reconstruction* of the face value. This module uses the
26//! latter — one reconstructed face value per direction, not two flux
27//! evaluations combined — since it avoids re-deriving/re-exposing
28//! `operators::fv`'s low/high flux formulas as a dependency of this module;
29//! the two are mathematically identical for this scalar `F = v·u` advective
30//! term.
31//!
32//! For `v ≥ 0` (window `{a, b, c} = {u[i−1], u[i], u[i+1]}`, the same
33//! offsets `operators::weno`'s `weno3_left` uses):
34//! ```text
35//! r = (b − a) / (c − b)                  (upstream slope / downstream slope)
36//! u_face = b + 0.5·φ(r)·(c − b)
37//! ```
38//! `v < 0` mirrors this (window `{b, c, d} = {u[i], u[i+1], u[i+2]}`, same
39//! offsets as `weno3_right`):
40//! ```text
41//! r = (d − c) / (c − b)
42//! u_face = c − 0.5·φ(r)·(c − b)
43//! ```
44//! `φ(r) = 0` recovers pure upwind (1st order, always non-oscillatory);
45//! `φ(r) = 1` recovers a centered/Lax–Wendroff-type correction (2nd order,
46//! can oscillate) — every limiter here interpolates between the two based
47//! on the local ratio of consecutive slopes `r`. The diffusive term is
48//! always the direct centered difference between the two nodes adjacent to
49//! the face, exactly as in `operators::fv`/`operators::weno`.
50//!
51//! ## Cell semantics
52//!
53//! Same cell-average interpretation as `operators::fv` (DD-040) and
54//! `operators::weno` (DD-041) — `u[i]` is the average of `u` over the cell
55//! whose faces sit at nodes `i` and `i+1`.
56//!
57//! ## `r = 0/0` (locally constant field)
58//!
59//! `ratio` (the helper computing `r`) returns `0.0` when the denominator is smaller than a fixed
60//! epsilon, rather than propagating a `NaN`. This is safe in both cases it
61//! covers: a genuinely constant local field also has a numerator near zero,
62//! so `c − b ≈ 0` makes the face value insensitive to `φ`'s exact value
63//! regardless; a genuine local extremum (numerator non-negligible, opposite
64//! or discontinuous slope) is exactly where every limiter here is designed
65//! to clip toward pure upwind — every `Limiter::phi` maps `r ≤ 0` to `0`, so
66//! defaulting the ill-conditioned ratio to `0.0` lands on the same
67//! non-oscillatory choice a genuine extremum would demand, not an arbitrary
68//! one.
69//!
70//! ## `FluxBoundary` and CFL
71//!
72//! Reuses [`crate::operators::FluxBoundary`], [`crate::operators::check_cfl`],
73//! and the same wide-stencil boundary helpers `operators::weno` uses
74//! (`periodic_wide_divergence`, `truncated_wide_divergence`,
75//! `ghost_cell_wide_divergence`, relocated to `operators` — see their
76//! module-level doc there) — `LimitedFlux`'s stencil footprint is exactly
77//! `WENO3`'s (`{i−1, i, i+1}` for `v ≥ 0`, `{i, i+1, i+2}` for `v < 0`), so
78//! the same margins apply: `Truncation` uses `(1, 1)`/`(0, 2)`;
79//! `GhostCell` uses `(2, 1)`/`(1, 2)` (one extra layer on the left — see
80//! `operators::weno`'s `GhostCell` match arm for why).
81//!
82//! ## Adaptive WENO/limiter selection — `operators::adaptive`
83//!
84//! The originating issue (`#99`) also calls for an adaptive scheme that
85//! picks WENO where the solution is smooth and a limiter where it is steep.
86//! That selection logic lives in [`crate::operators::adaptive::AdaptiveFlux`],
87//! not here — it reuses `WENO3`'s own smoothness indicator per cell, gated
88//! by a global Péclet-number threshold (velocity/diffusion are constant in
89//! this module's scope, so a genuinely *local* Péclet number has no meaning
90//! here — see that module's documentation for the full rationale).
91//!
92//! [`UniformGrid1D`]: crate::mesh::structured::UniformGrid1D

108/// Ratio of consecutive slopes with a safe `0/0` fallback — see the module
109/// documentation ("`r = 0/0`") for why `0.0` is the correct default, not
110/// merely a convenient one.
111fn ratio(numer: f64, denom: f64) -> f64 {
112    const EPS: f64 = 1e-12;
113    if denom.abs() < EPS {
114        0.0
115    } else {
116        numer / denom
117    }
118}

120// ── Limiter ───────────────────────────────────────────────────────────────────
121
122/// Slope limiter function `φ(r)`, `r` the ratio of consecutive slopes.
123///
124/// All three satisfy `φ(r) = 0` for `r ≤ 0` (no correction at a local
125/// extremum or discontinuous slope — pure upwind, non-oscillatory) and
126/// `φ(1) = 1` (exact for a locally linear field, 2nd order there). They
127/// differ in how much high-order correction they allow for `r > 1`:
128/// `MinMod` caps at `1` (most diffusive/restrictive), `Superbee` reaches `2`
129/// fastest (least diffusive, most compressive — can steepen contact
130/// discontinuities), `VanLeer` sits strictly between the two — a smooth,
131/// differentiable compromise. This ordering
132/// (`MinMod ≤ VanLeer ≤ Superbee` for `r > 1`) is `#99`'s acceptance
133/// criterion, checked directly in the tests below.
134#[non_exhaustive]
135#[derive(Debug, Clone, Copy, PartialEq, Eq)]
136pub enum Limiter {
137    /// `φ(r) = max(0, min(1, r))` — most diffusive of the three.
138    MinMod,
139    /// `φ(r) = (r + |r|) / (1 + |r|)` — smooth, strictly between `MinMod`
140    /// and `Superbee` for `r > 1`.
141    VanLeer,
142    /// `φ(r) = max(0, min(2r, 1), min(r, 2))` — least diffusive, saturates
143    /// at `2`.
144    Superbee,
145}
146
147impl Limiter {
148    /// Evaluates `φ(r)`.
149    pub fn phi(&self, r: f64) -> f64 {
150        match self {
151            Limiter::MinMod => r.clamp(0.0, 1.0),
152            Limiter::VanLeer => (r + r.abs()) / (1.0 + r.abs()),
153            Limiter::Superbee => {
154                let a = (2.0 * r).min(1.0);
155                let b = r.min(2.0);
156                a.max(b).max(0.0)
157            }
158        }
159    }
160}

162// ── LimitedFlux ───────────────────────────────────────────────────────────────
163
164/// Flux-limited (MUSCL) advective flux + centered Fick's-law diffusive
165/// flux, 2nd order where smooth, non-oscillatory near discontinuities.
166///
167/// `F(u, ∇u) = v·u − D·∂u/∂x` — see the module documentation for the
168/// reconstruction formula and boundary treatment.
169#[derive(Debug, Clone)]
170pub struct LimitedFlux {
171    velocity: f64,
172    diffusion: f64,
173    limiter: Limiter,
174    boundary: FluxBoundary,
175}
176
177impl LimitedFlux {
178    /// Creates a flux-limited operator using `limiter`.
179    pub fn new(velocity: f64, diffusion: f64, limiter: Limiter, boundary: FluxBoundary) -> Self {
180        Self {
181            velocity,
182            diffusion,
183            limiter,
184            boundary,
185        }
186    }
187
188    pub(crate) fn face_flux(&self, dx: f64, u: &DVector<f64>, n: usize, i: usize) -> f64 {
189        let v = self.velocity;
190        let u_face = if v >= 0.0 {
191            let (a, b, c) = (u[wrap(i, -1, n)], u[i], u[wrap(i, 1, n)]);
192            let r = ratio(b - a, c - b);
193            b + 0.5 * self.limiter.phi(r) * (c - b)
194        } else {
195            let (b, c, d) = (u[i], u[wrap(i, 1, n)], u[wrap(i, 2, n)]);
196            let r = ratio(d - c, c - b);
197            c - 0.5 * self.limiter.phi(r) * (c - b)
198        };
199        let diffusive = self.diffusion * (u[wrap(i, 1, n)] - u[i]) / dx;
200        v * u_face - diffusive
201    }
202}
203
204impl RequiresContext for LimitedFlux {
205    fn required_variables(&self) -> Vec<ContextVariable> {
206        // Constant velocity/diffusion — nothing to resolve from ComputeContext
207        // (the "simple case" of DD-039, same posture as FV/WENO).
208        vec![]
209    }
210}

212impl FluxDivergenceOperator for LimitedFlux {
213    type MeshType = UniformGrid1D;
214
215    fn apply(
216        &self,
217        field: &ContextValue,
218        mesh: &Self::MeshType,
219        ctx: &ComputeContext,
220    ) -> Result<ContextValue, OxiflowError> {
221        let u = field.as_scalar_field()?;
222        let dx = mesh.characteristic_length();
223        check_cfl("LimitedFlux", self.velocity, ctx.time_step(), dx)?;
224
225        let div = match &self.boundary {
226            FluxBoundary::Periodic => {
227                periodic_wide_divergence(u, dx, 3, "LimitedFlux", |u, n, i| {
228                    self.face_flux(dx, u, n, i)
229                })?
230            }
231            FluxBoundary::Truncation => {
232                // Same stencil footprint as WENO3 — see the module doc.
233                let (margin_left, margin_right) =
234                    if self.velocity >= 0.0 { (1, 1) } else { (0, 2) };
235                truncated_wide_divergence(
236                    u,
237                    dx,
238                    margin_left,
239                    margin_right,
240                    "LimitedFlux",
241                    |u, n, i| self.face_flux(dx, u, n, i),
242                )?
243            }
244            FluxBoundary::GhostCell(left_bc, right_bc) => {
245                let margins = if self.velocity >= 0.0 { (2, 1) } else { (1, 2) };
246                ghost_cell_wide_divergence(
247                    u,
248                    dx,
249                    margins,
250                    (left_bc.as_ref(), right_bc.as_ref()),
251                    "LimitedFlux",
252                    |u, n, i| self.face_flux(dx, u, n, i),
253                )?
254            }
255        };
256        Ok(ContextValue::ScalarField(div))
257    }
258}

413    #[test]
414    fn ghost_cell_left_biased_matches_hand_built_extended_field() {
415        use std::sync::Arc;
416
417        let values = vec![0.2, 1.3, -0.7, 2.1, 0.0];
418        let m = mesh(values.len());
419        let dx = m.characteristic_length();
420        let u = ContextValue::ScalarField(DVector::from_vec(values.clone()));
421        let g = 0.5;
422        let left_bc = Arc::new(DirichletGhost(g));
423        let right_bc = Arc::new(DirichletGhost(g));
424        let op = LimitedFlux::new(
425            1.0,
426            0.0,
427            Limiter::VanLeer,
428            FluxBoundary::GhostCell(left_bc, right_bc),
429        );
430        let div = op.apply(&u, &m, &ctx(0.001 * dx)).unwrap();
431        let div = div.as_scalar_field().unwrap();
432
433        let n = values.len();
434        let ghost_m2 = 2.0 * g - values[1];
435        let ghost_m1 = 2.0 * g - values[0];
436        let ghost_p1 = 2.0 * g - values[n - 1];
437        let mut extended = vec![ghost_m2, ghost_m1];
438        extended.extend(values.iter().copied());
439        extended.push(ghost_p1);
440        let ext = DVector::from_vec(extended);
441        let m_ext = ext.len();
442
443        let probe = LimitedFlux::new(1.0, 0.0, Limiter::VanLeer, FluxBoundary::Periodic);
444        let face = |i: usize| probe.face_flux(dx, &ext, m_ext, i);
445        let expected_0 = (face(2) - face(1)) / dx;
446        let expected_last = (face(2 + n - 1) - face(2 + n - 2)) / dx;
447        assert!((div[0] - expected_0).abs() < 1e-10, "got {}", div[0]);
448        assert!(
449            (div[n - 1] - expected_last).abs() < 1e-10,
450            "got {}",
451            div[n - 1]
452        );
453    }
