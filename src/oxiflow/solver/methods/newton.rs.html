1//! # Module `solver::methods::newton`
2//!
3//! Iterated Newton solver — shared, integrator-agnostic core ([DD-044](https://github.com/biface/oxiflow/issues/109),
4//! issue [#109](https://github.com/biface/oxiflow/issues/109), activating
5//! [DD-033](https://github.com/biface/oxiflow/issues/86)'s ([#86](https://github.com/biface/oxiflow/issues/86)) Option A).
6//!
7//! ## Why this exists
8//!
9//! `super::implicit::theta_method_step` and `bdf2_step`
10//! (through v0.6.0) each performed exactly **one** Newton-style
11//! correction with a frozen Jacobian — exact when the underlying
12//! `compute_physics` is affine in `u`, a first-order approximation
13//! otherwise. This module provides the genuinely iterated alternative
14//! [DD-033](https://github.com/biface/oxiflow/issues/86) always anticipated, shared by both call sites rather than
15//! duplicated: theta-method and BDF2 (this sprint's two concrete
16//! consumers) differ only in how they express their residual as an
17//! affine transform of `u` plus an implicit term — see
18//! [the residual convention](#residual-convention) below.
19//!
20//! ## Residual convention
21//!
22//! Both consumers' implicit equations reduce to the same shape:
23//!
24//! $$g(u) = \alpha (u - u^{*}) - c \cdot f(u)$$
25//!
26//! - **theta-method** (Backward Euler `θ=1`, Crank-Nicolson `θ=0.5`):
27//!   $\alpha = 1$, $c = \theta \Delta t$, $u^{*} = u^n + \Delta t(1-\theta)
28//!   f(u^n)$.
29//! - **BDF2**: $\alpha = 3/2$, $c = \Delta t$, $u^{*} = \frac{4u^n -
30//!   u^{n-1}}{3}$.
31//!
32//! `u^{*}` folds in every term that doesn't depend on the unknown `u` —
33//! callers compute it once, outside the loop, from already-known past
34//! states. `residual` evaluates this shape, a `NewtonSystem` holds and
35//! solves its linearisation $\alpha I - c J_f$, and `solve` is the generic
36//! loop wiring them together with a [`NewtonConvergence`] criterion and a
37//! [`JacobianStrategy`].
38//!
39//! ## Dense/sparse agnosticism
40//!
41//! This module knows nothing about `Domain`, `ContextCalculator`, or
42//! `faer` — `solve` is parameterised over a caller-supplied closure for
43//! evaluating $f(u)$ and over a `NewtonSystem`, which assembles
44//! $A = \alpha I - c J_f$ at an iterate and solves $A \delta u = -g(u)$
45//! in its own storage format. The convergence test, the iteration budget
46//! and the Jacobian refresh strategy belong to the loop, whatever the
47//! format. `DenseNewtonSystem` is the dense implementation.
48//!
49//! ## Wiring status
50//!
51//! `solve` is called from a single place, the implicit step of
52//! [`super::implicit`] ([DD-044](https://github.com/biface/oxiflow/issues/109),
53//! [#111](https://github.com/biface/oxiflow/issues/111),
54//! [#112](https://github.com/biface/oxiflow/issues/112)), which expresses
55//! each integrator's equation in the residual convention above
56//! (`ImplicitFormula`) and supplies the dense or the banded
57//! `NewtonSystem`. It serves
58//! [`BackwardEulerSolver`](super::backward_euler::BackwardEulerSolver),
59//! [`CrankNicolsonSolver`](super::crank_nicolson::CrankNicolsonSolver) and
60//! [`BDF2Solver`](super::bdf2::BDF2Solver), whose Backward Euler
61//! bootstrap step runs with the same configuration as its BDF2 update.

70/// Convergence criterion for the iterated Newton loop (`solve`).
71///
72/// Every variant carries the same `tol_abs`/`tol_rel` pair: convergence
73/// is tested against `tol_abs + tol_rel * ||u||`, evaluated on the
74/// iterate *after* applying the current correction (so that, e.g.,
75/// `max_iterations = 1` with an exactly affine `f` succeeds immediately —
76/// the single correction is already exact up to floating-point rounding).
77///
78/// Default: [`ResidualOnly`](Self::ResidualOnly) with `tol_abs = 1e-8`,
79/// `tol_rel = 1e-6` — starting points, not fixed constants; tune via the
80/// solver builders once this lands ([#111](https://github.com/biface/oxiflow/issues/111)/[#112](https://github.com/biface/oxiflow/issues/112)).
81///
82/// Note: this default is *not* what the implicit solvers' zero-config
83/// constructors and the defaults of `IntegratorSpec` use — both take
84/// `stiff_jacobian_convergence`, a looser, explicitly named tolerance
85/// needed to guarantee the pre-[DD-044](https://github.com/biface/oxiflow/issues/109)
86/// single-correction contract on very stiff affine problems (see
87/// [`super::implicit`]'s module docs for why). This `Default` impl is a
88/// general starting point for callers configuring the loop themselves,
89/// not a guarantee that it tolerates every finite-difference precision
90/// floor.
91#[non_exhaustive]
92#[derive(Debug, Clone, Copy, PartialEq)]
93#[cfg_attr(feature = "serde", derive(serde::Deserialize))]
94pub enum NewtonConvergence {
95    /// Converged once `||g(u)|| < tol_abs + tol_rel * ||u||`.
96    ///
97    /// The residual is available at zero extra cost — `f(u)` is already
98    /// evaluated to build the next correction — so this is the cheapest
99    /// criterion, not merely the default for convenience.
100    ResidualOnly { tol_abs: f64, tol_rel: f64 },
101    /// Converged once **either** the residual **or** the correction norm
102    /// (`||δu||`) satisfies the tolerance.
103    CombinedOr { tol_abs: f64, tol_rel: f64 },
104    /// Converged only once **both** the residual **and** the correction
105    /// norm satisfy the tolerance — the strictest of the three.
106    CombinedAnd { tol_abs: f64, tol_rel: f64 },
107}
108
109impl Default for NewtonConvergence {
110    fn default() -> Self {
111        NewtonConvergence::ResidualOnly {
112            tol_abs: 1e-8,
113            tol_rel: 1e-6,
114        }
115    }
116}
117
118impl NewtonConvergence {
119    /// Extracts the common `(tol_abs, tol_rel)` pair, regardless of
120    /// variant.
121    fn tolerances(&self) -> (f64, f64) {
122        match *self {
123            NewtonConvergence::ResidualOnly { tol_abs, tol_rel }
124            | NewtonConvergence::CombinedOr { tol_abs, tol_rel }
125            | NewtonConvergence::CombinedAnd { tol_abs, tol_rel } => (tol_abs, tol_rel),
126        }
127    }
128}

130/// Jacobian refresh strategy for the iterated Newton loop (`solve`).
131///
132/// Default: [`ModifiedFrozen`](Self::ModifiedFrozen) — matches the
133/// pre-[DD-044](https://github.com/biface/oxiflow/issues/109) behaviour (Jacobian evaluated once, at the initial guess,
134/// never refreshed) as a special case of the generic loop, rather than a
135/// separate code path.
136#[non_exhaustive]
137#[derive(Debug, Clone, Copy, PartialEq, Default)]
138#[cfg_attr(feature = "serde", derive(serde::Deserialize))]
139pub enum JacobianStrategy {
140    /// Evaluate the Jacobian once, at the initial guess, and reuse it for
141    /// every correction (modified Newton).
142    #[default]
143    ModifiedFrozen,
144    /// Re-evaluate the Jacobian at every iterate (full Newton) — most
145    /// robust on strongly nonlinear problems, at the cost of one
146    /// `finite_difference_jacobian`
147    /// (or its banded equivalent) per iteration.
148    FullNewton,
149    /// Reuse the frozen Jacobian while convergence is proceeding
150    /// acceptably; re-evaluate it once the residual stops shrinking fast
151    /// enough. Refreshed whenever
152    /// `residual_norm_k / residual_norm_{k-1} > stagnation_ratio` — an
153    /// explicit extension point for cost/robustness tuning, not yet
154    /// auto-tuned.
155    ModifiedWithStagnationCheck { stagnation_ratio: f64 },
156}

160/// Evaluates the residual $g(u) = \alpha (u - u^{*}) - c \cdot f(u)$ — see
161/// the [module docs](self#residual-convention) for what `alpha`/`coeff`/
162/// `u_star` mean for each of this loop's two consumers.
163///
164/// `f_u` is `f(u)`, already evaluated by the caller (it is also needed
165/// to decide, e.g., whether to refresh the Jacobian — evaluating it here
166/// again would be redundant).
167pub(crate) fn residual(
168    u: &DVector<f64>,
169    u_star: &DVector<f64>,
170    alpha: f64,
171    coeff: f64,
172    f_u: &DVector<f64>,
173) -> DVector<f64> {
174    let delta: DVector<f64> = u - u_star;
175    delta * alpha - f_u.clone() * coeff
176}
177
178/// The linear system of one Newton solve, $A = \alpha I - c J_f$, in a
179/// given storage format.
180///
181/// [`solve`] calls [`assemble`](Self::assemble) at the initial iterate
182/// and whenever its [`JacobianStrategy`] refreshes the Jacobian, and
183/// [`solve`](Self::solve) once per iteration with the last assembled
184/// matrix. `alpha` and `coeff` are those of the residual (see the
185/// [residual convention](self#residual-convention)); they do not change
186/// during one Newton solve, so the matrix is assembled once per refresh
187/// rather than once per iteration.
188pub(crate) trait NewtonSystem {
189    /// Evaluates $J_f$ at `u` and assembles $A = \alpha I - c J_f$,
190    /// replacing the previously assembled matrix.
191    fn assemble(&mut self, u: &DVector<f64>, alpha: f64, coeff: f64) -> Result<(), OxiflowError>;
192
193    /// Solves $A x = $ `rhs` with the last assembled $A$.
194    ///
195    /// # Errors
196    ///
197    /// `OxiflowError::PreconditionFailed` if no matrix has been assembled
198    /// yet; any error of the linear solver.
199    fn solve(&self, rhs: &DVector<f64>) -> Result<DVector<f64>, OxiflowError>;
200}
201
202/// Dense [`NewtonSystem`]: `jacobian` evaluates $J_f$ as a `DMatrix`
203/// (in production, [`finite_difference_jacobian`](super::implicit::finite_difference_jacobian)),
204/// and `linear_solver` solves the assembled system.
205pub(crate) struct DenseNewtonSystem<'a, J> {
206    jacobian: J,
207    linear_solver: &'a dyn LinearSolver,
208    matrix: Option<DMatrix<f64>>,
209}
210
211impl<'a, J> DenseNewtonSystem<'a, J>
212where
213    J: FnMut(&DVector<f64>) -> Result<DMatrix<f64>, OxiflowError>,
214{
215    /// A system with no matrix assembled yet.
216    pub(crate) fn new(jacobian: J, linear_solver: &'a dyn LinearSolver) -> Self {
217        Self {
218            jacobian,
219            linear_solver,
220            matrix: None,
221        }
222    }
223}
224
225impl<J> NewtonSystem for DenseNewtonSystem<'_, J>
226where
227    J: FnMut(&DVector<f64>) -> Result<DMatrix<f64>, OxiflowError>,
228{
229    fn assemble(&mut self, u: &DVector<f64>, alpha: f64, coeff: f64) -> Result<(), OxiflowError> {
230        let jacobian = (self.jacobian)(u)?;
231        let n = jacobian.nrows();
232        self.matrix = Some(DMatrix::<f64>::identity(n, n) * alpha - jacobian * coeff);
233        Ok(())
234    }
235
236    fn solve(&self, rhs: &DVector<f64>) -> Result<DVector<f64>, OxiflowError> {
237        let matrix = self
238            .matrix
239            .as_ref()
240            .ok_or_else(|| OxiflowError::PreconditionFailed {
241                context: "DenseNewtonSystem::solve",
242                message: "no matrix assembled".into(),
243            })?;
244        self.linear_solver.solve(matrix, rhs)
245    }
246}

250/// Parameters governing the iterated Newton loop ([`solve`]), gathered
251/// into one struct so the loop's own argument list stays manageable
252/// alongside the residual-shape parameters (`u_star`/`alpha`/`coeff`)
253/// and the two evaluation closures.
254#[derive(Debug, Clone, Copy)]
255pub(crate) struct NewtonParams {
256    pub convergence: NewtonConvergence,
257    pub jacobian_strategy: JacobianStrategy,
258    pub max_iterations: usize,
259}
260
261/// Runs the iterated Newton loop for $g(u) = \alpha(u - u^{*}) - c f(u) =
262/// 0$, starting from `u0`.
263///
264/// `f_eval` evaluates $f(u)$ for a candidate iterate (in production,
265/// this wraps [`evaluate_derivative`](super::evaluate_derivative) —
266/// including its boundary-condition re-application, see
267/// [`super::implicit`]'s known-limitation note); `system` assembles and
268/// solves the linearised system at a candidate iterate (see
269/// [`NewtonSystem`]). `f_eval` and `system.assemble` are each called at
270/// most `max_iterations + 1` times.
271///
272/// Convergence is checked **after** applying each correction, uniformly
273/// regardless of `max_iterations` — there is no special case for
274/// `max_iterations == 1`. This is deliberate: whether `f` is affine in
275/// `u` is not tracked or asserted anywhere (doing so would require the
276/// HOW pole to know something about the WHAT pole's `PhysicalModel`,
277/// which [DD-044](https://github.com/biface/oxiflow/issues/109) does not introduce) — it is instead *inferred for free*
278/// from the residual itself. For an affine `f`, a single correction is
279/// exact, so the post-application residual already sits at
280/// floating-point precision and passes any reasonable tolerance; for a
281/// genuinely nonlinear `f`, it generally does not, and
282/// `max_iterations == 1` then correctly reports
283/// [`OxiflowError::NewtonNotConverged`] instead of silently returning a
284/// first-order-accurate value.
285///
286/// Consequence for callers migrating from the pre-[DD-044](https://github.com/biface/oxiflow/issues/109)
287/// `theta_method_step`/`bdf2_step` (which never checked convergence, and
288/// so could never fail this way): calling this loop with the historical
289/// defaults (`max_iterations = 1`, `ModifiedFrozen`) reproduces the exact
290/// same numeric result on every existing (affine) regression case, but
291/// — unlike before — now surfaces an explicit error rather than a silent
292/// first-order approximation on a genuinely nonlinear model. Widen
293/// `max_iterations` (or the tolerance) for such models rather than
294/// relying on the single-correction default.
295///
296/// # Errors
297///
298/// Returns [`OxiflowError::NewtonNotConverged`] if `max_iterations` is
299/// exhausted without satisfying `params.convergence`. Propagates any
300/// error from `f_eval` or from `system` unchanged.
301pub(crate) fn solve(
302    u0: DVector<f64>,
303    u_star: &DVector<f64>,
304    alpha: f64,
305    coeff: f64,
306    mut f_eval: impl FnMut(&DVector<f64>) -> Result<DVector<f64>, OxiflowError>,
307    system: &mut impl NewtonSystem,
308    params: &NewtonParams,
309) -> Result<DVector<f64>, OxiflowError> {
310    let (tol_abs, tol_rel) = params.convergence.tolerances();
311
312    let mut u = u0;
313    system.assemble(&u, alpha, coeff)?;
314    let mut f_u = f_eval(&u)?;
315    let mut prev_residual_norm: Option<f64> = None;
316    let mut last_residual_norm = f64::INFINITY;
317
318    for _ in 0..params.max_iterations {
319        let res = residual(&u, u_star, alpha, coeff, &f_u);
320        let correction = system.solve(&-res)?;
321        let correction_norm = correction.norm();
322        u += correction;
323
324        f_u = f_eval(&u)?;
325        let res_new = residual(&u, u_star, alpha, coeff, &f_u);
326        let res_new_norm = res_new.norm();
327        last_residual_norm = res_new_norm;
328
329        let tol = tol_abs + tol_rel * u.norm();
330        let residual_ok = res_new_norm < tol;
331        let correction_ok = correction_norm < tol;
332        let converged = match params.convergence {
333            NewtonConvergence::ResidualOnly { .. } => residual_ok,
334            NewtonConvergence::CombinedOr { .. } => residual_ok || correction_ok,
335            NewtonConvergence::CombinedAnd { .. } => residual_ok && correction_ok,
336        };
337        if converged {
338            return Ok(u);
339        }
340
341        match params.jacobian_strategy {
342            JacobianStrategy::ModifiedFrozen => {}
343            JacobianStrategy::FullNewton => {
344                system.assemble(&u, alpha, coeff)?;
345            }
346            JacobianStrategy::ModifiedWithStagnationCheck { stagnation_ratio } => {
347                let stagnating = prev_residual_norm
348                    .map(|prev| prev > 0.0 && res_new_norm / prev > stagnation_ratio)
349                    .unwrap_or(false);
350                if stagnating {
351                    system.assemble(&u, alpha, coeff)?;
352                }
353            }
354        }
355        prev_residual_norm = Some(res_new_norm);
356    }
357
358    Err(OxiflowError::NewtonNotConverged {
359        iterations: params.max_iterations,
360        residual: last_residual_norm,
361    })
362}

371    // Two synthetic, domain-free test problems — this module is
372    // integrator-agnostic, so its own tests exercise `solve` directly
373    // against hand-written f/jacobian closures rather than a full
374    // Domain/Scenario, unlike `implicit.rs`/`bdf2.rs`'s tests.
375
376    /// Boxed rather than `impl FnMut` (clippy::type_complexity on the
377    /// pair below) — `solve()` and `DenseNewtonSystem` take `impl FnMut`,
378    /// which `Box<dyn FnMut>` satisfies automatically, so boxing here
379    /// costs nothing but an allocation in test setup.
380    type StateFn = Box<dyn FnMut(&DVector<f64>) -> Result<DVector<f64>, OxiflowError>>;
381    type JacobianFn = Box<dyn FnMut(&DVector<f64>) -> Result<DMatrix<f64>, OxiflowError>>;
382
383    /// f(u) = -lambda*u — affine, so a single correction is exact
384    /// regardless of `max_iterations`/`jacobian_strategy`.
385    fn affine_decay(lambda: f64) -> (StateFn, JacobianFn) {
386        let f = move |u: &DVector<f64>| Ok(u.map(|v| -lambda * v));
387        let jac =
388            move |u: &DVector<f64>| Ok(DMatrix::<f64>::identity(u.len(), u.len()) * (-lambda));
389        (Box::new(f), Box::new(jac))
390    }
391
392    /// f(u) = -u^3 — genuinely nonlinear; one frozen-Jacobian correction
393    /// is only a first-order approximation, iterated Newton is needed
394    /// for tight convergence.
395    fn cubic_decay() -> (StateFn, JacobianFn) {
396        let f = move |u: &DVector<f64>| Ok(u.map(|v| -v * v * v));
397        let jac =
398            move |u: &DVector<f64>| Ok(DMatrix::<f64>::from_diagonal(&u.map(|v| -3.0 * v * v)));
399        (Box::new(f), Box::new(jac))
400    }

563    #[test]
564    fn combined_or_converges_when_correction_is_small_even_if_residual_is_not() {
565        let f = |u: &DVector<f64>| Ok(u.map(|v| v + 1.0)); // never zero for u >= 0
566        let jac = |u: &DVector<f64>| Ok(DMatrix::<f64>::identity(u.len(), u.len()) * -1.0e6);
567        let u0 = DVector::from_element(1, 0.0);
568        let u_star = u0.clone();
569        // A deliberately stiff Jacobian (-1e6) makes the correction
570        // collapse to a tiny step even though the residual itself does
571        // not shrink below tolerance -- see the closures above.
572        let params_or = NewtonParams {
573            convergence: NewtonConvergence::CombinedOr {
574                tol_abs: 1e-3,
575                tol_rel: 0.0,
576            },
577            jacobian_strategy: JacobianStrategy::ModifiedFrozen,
578            max_iterations: 1,
579        };
580        let params_residual_only = NewtonParams {
581            convergence: NewtonConvergence::ResidualOnly {
582                tol_abs: 1e-3,
583                tol_rel: 0.0,
584            },
585            jacobian_strategy: JacobianStrategy::ModifiedFrozen,
586            max_iterations: 1,
587        };
588
589        let out_or = solve(
590            u0.clone(),
591            &u_star,
592            1.0,
593            1.0,
594            f,
595            &mut DenseNewtonSystem::new(jac, &NalgebraDenseSolver),
596            &params_or,
597        );
598        let out_residual_only = solve(
599            u0,
600            &u_star,
601            1.0,
602            1.0,
603            f,
604            &mut DenseNewtonSystem::new(jac, &NalgebraDenseSolver),
605            &params_residual_only,
606        );
607
608        assert!(out_or.is_ok(), "CombinedOr should accept a tiny correction");
609        assert!(
610            out_residual_only.is_err(),
611            "ResidualOnly should reject a large residual"
612        );
613    }
