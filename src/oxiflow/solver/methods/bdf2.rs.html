1//! # Module `solver::methods::bdf2`
2//!
3//! BDF2 integrator — implicit multi-step, 2nd order (issue [#44](https://github.com/biface/oxiflow/issues/44)).
4//!
5//! ## Algorithm
6//!
7//! $$\frac{3}{2}u^{n+1} - 2u^n + \frac{1}{2}u^{n-1} = \Delta t \cdot f(u^{n+1}, t^{n+1})$$
8//!
9//! Unlike Backward Euler / Crank-Nicolson ([`super::implicit`]), this needs
10//! **two** past states, not one — `SteppableSolver::history_depth()`
11//! returns `1` here ([DD-034](https://github.com/biface/oxiflow/issues/87)), and [`BDF2Solver::step`] receives `u^{n-1}`
12//! via the `history` parameter.
13//!
14//! The BDF2 update is the `ImplicitFormula::Bdf2` formula of
15//! [`super::implicit`]: $\alpha = 3/2$, $c = \Delta t$, $u^{*} =
16//! \frac{4u^n - u^{n-1}}{3}$ in [`super::newton`]'s residual convention.
17//! It runs through `super::implicit::implicit_step_newton`, like the
18//! theta method, so the Newton loop, the residual, the finite-difference
19//! Jacobian and the solver's `NewtonParams` are those of the other
20//! implicit solvers ([DD-044](https://github.com/biface/oxiflow/issues/109), [#112](https://github.com/biface/oxiflow/issues/112)).
21//!
22//! ## Startup (acceptance criterion, [#44](https://github.com/biface/oxiflow/issues/44))
23//!
24//! BDF2 needs `u^{n-1}`, which doesn't exist at the very first step. When
25//! `history` is empty, [`BDF2Solver::step`] falls back to a single
26//! Backward Euler step (`ImplicitFormula::Theta(1.0)`)
27//! to produce `u^1` from `u^0` — the standard bootstrap for 2-step methods.
28//! From the second step onward, the real BDF2 update runs.
29//!
30//! The bootstrap step runs the same iterated Newton loop as the BDF2
31//! update, with the solver's own convergence criterion, Jacobian
32//! strategy and iteration budget: a nonlinear model gets the budget it
33//! was configured with from the first step on. With the default
34//! configuration, the bootstrap step is the single frozen-Jacobian
35//! correction it has always been.
36//!
37//! ## Scope — fixed `dt` only
38//!
39//! *"Step-size change logic for adaptive dt"* (as [#44](https://github.com/biface/oxiflow/issues/44) originally asked)
40//! is **not implemented**: this solver rejects `StepControl::Adaptive`,
41//! which only `DoPri45Solver` ([#42](https://github.com/biface/oxiflow/issues/42)) accepts. A variable-step BDF2 would
42//! need the classical fixed-step coefficients used here (3/2, -2, 1/2) to
43//! become ratio-dependent for a varying step size between `u^{n-1}` and
44//! `u^n`, and an error estimate to drive the step; no model needs it yet.
45//!
46//! ## State variants
47//!
48//! The update works on the flat vector of unknowns given by `StateLayout`
49//! (`super::state_layout`), as the θ-method does: a `VectorField` state,
50//! interleaved by node, is advanced like a `ScalarField`, and so is the
51//! Backward Euler startup step ([#192](https://github.com/biface/oxiflow/issues/192)). For a `ScalarField`, results are
52//! bit-identical to the former code.
53//!
54//! ## Banded path (feature `sparse`, [DA-043](https://github.com/biface/oxiflow/issues/103))
55//!
56//! Like [`BackwardEulerSolver`](super::backward_euler::BackwardEulerSolver)
57//! and [`CrankNicolsonSolver`](super::crank_nicolson::CrankNicolsonSolver),
58//! the solver takes a banded linear system once a sparse solver
59//! (`with_sparse_solver`) and a Jacobian half-bandwidth
60//! (`with_jacobian_bandwidth`) are configured and the system has more
61//! unknowns than `with_sparse_threshold` (default 100). The bootstrap
62//! step and the BDF2 update both take it, through the same Newton loop
63//! and with the same Newton parameters as the dense path ([#133](https://github.com/biface/oxiflow/issues/133)).
64//!
65//! ## Stability
66//!
67//! A-stable and, unlike Crank-Nicolson, L-stable — strong damping on
68//! stiff modes, same qualitative behaviour as Backward Euler but 2nd
69//! order accurate.

83/// BDF2 solver — implicit multi-step, 2nd order.
84///
85/// See [module docs](self) for the startup phase and the fixed-`dt`-only
86/// scope.
87///
88/// # Newton settings
89///
90/// Each step, the startup step included, solves its implicit equation by Newton's method, by default
91/// with a single frozen-Jacobian correction, exact on a model affine in
92/// `u`. A nonlinear model, or a fine grid on the banded path, may need a
93/// larger budget (`with_max_newton_iterations`), another Jacobian strategy
94/// (`with_jacobian_strategy`) or another convergence criterion
95/// (`with_newton_convergence`): see
96/// [`OxiflowError::NewtonNotConverged`] for the defaults and the typical
97/// cases.
98///
99/// # Examples
100///
101/// ```rust
102/// use oxiflow::solver::methods::bdf2::BDF2Solver;
103///
104/// // Dense path (default).
105/// let solver = BDF2Solver::new();
106///
107/// // Banded path (feature `sparse`, DA-043): the dense path stays
108/// // untouched unless a sparse solver and a bandwidth are both configured.
109/// # #[cfg(feature = "sparse")]
110/// # {
111/// use oxiflow::solver::sparse::FaerSparseSolver;
112/// let banded = BDF2Solver::new()
113///     .with_jacobian_bandwidth(3) // two interleaved components, stencil half-width 1
114///     .with_sparse_solver(Box::new(FaerSparseSolver))
115///     .with_sparse_threshold(100); // default
116/// # }
117/// ```
118#[derive(Default)]
119pub struct BDF2Solver {
120    /// Linear-system backends ([DT-013](https://github.com/biface/oxiflow/issues/13), [DA-043](https://github.com/biface/oxiflow/issues/103)): the dense solver and,
121    /// with the `sparse` feature, the banded-path configuration, set by
122    /// `with_linear_solver` and the `with_sparse_*`/`with_jacobian_bandwidth`
123    /// builders, for the startup step and the BDF2 update alike.
124    backend: ImplicitBackend,
125    /// Newton configuration ([DD-044](https://github.com/biface/oxiflow/issues/109), [#111](https://github.com/biface/oxiflow/issues/111)): convergence criterion,
126    /// Jacobian refresh strategy and iteration budget, set by the
127    /// `with_newton_convergence`/`with_jacobian_strategy`/
128    /// `with_max_newton_iterations` builders. Default
129    /// [`NewtonParams::default`]: a single frozen-Jacobian correction under
130    /// [`stiff_jacobian_convergence`](super::implicit::stiff_jacobian_convergence),
131    /// exact on affine problems; raise the
132    /// budget (typically with [`JacobianStrategy::FullNewton`]) for a
133    /// nonlinear model.
134    newton: NewtonParams,
135    /// Dispatch configuration of the finite-difference Jacobian assembly
136    /// ([DT-069](https://github.com/biface/oxiflow/issues/198)), for the startup step and the BDF2 update alike. Its
137    /// threshold exists only with the `parallel` feature — see
138    /// `with_parallel_threshold`.
139    jacobian_dispatch: JacobianDispatch,
140}
141
142impl BDF2Solver {
143    /// Creates a solver using the default `nalgebra` dense backend.
144    pub fn new() -> Self {
145        Self::default()
146    }
147
148    /// Substitutes the linear solver backend ([DT-013](https://github.com/biface/oxiflow/issues/13)).
149    pub fn with_linear_solver(mut self, linear_solver: Box<dyn LinearSolver>) -> Self {
150        self.backend.linear_solver = linear_solver;
151        self
152    }
153
154    /// Configures the Newton convergence criterion ([DD-044](https://github.com/biface/oxiflow/issues/109), [#112](https://github.com/biface/oxiflow/issues/112)), for the
155    /// Backward Euler bootstrap step and the BDF2 update alike (see
156    /// [module docs](self)).
157    pub fn with_newton_convergence(mut self, newton_convergence: NewtonConvergence) -> Self {
158        self.newton.convergence = newton_convergence;
159        self
160    }
161
162    /// Configures the Jacobian refresh strategy ([DD-044](https://github.com/biface/oxiflow/issues/109), [#112](https://github.com/biface/oxiflow/issues/112)).
163    pub fn with_jacobian_strategy(mut self, jacobian_strategy: JacobianStrategy) -> Self {
164        self.newton.jacobian_strategy = jacobian_strategy;
165        self
166    }
167
168    /// Configures the Newton iteration budget ([DD-044](https://github.com/biface/oxiflow/issues/109), [#112](https://github.com/biface/oxiflow/issues/112)) — see
169    /// [`BackwardEulerSolver::with_max_newton_iterations`](super::backward_euler::BackwardEulerSolver::with_max_newton_iterations).
170    pub fn with_max_newton_iterations(mut self, max_newton_iterations: usize) -> Self {
171        self.newton.max_iterations = max_newton_iterations;
172        self
173    }
174
175    /// Overrides the Rayon dispatch threshold of the finite-difference
176    /// Jacobian assembly at construction time ([DT-069](https://github.com/biface/oxiflow/issues/198)), in unknowns
177    /// (nodes × components). The Jacobian's columns (dense path) or colors
178    /// (banded path) are dispatched through Rayon once the system has at
179    /// least this many unknowns; the Jacobian is bit-for-bit identical
180    /// either way. Only exists when the crate is built with the `parallel`
181    /// feature.
182    ///
183    /// # Panics
184    ///
185    /// Panics when `threshold == 0` — see `ParallelThreshold::set`.
186    #[cfg(feature = "parallel")]
187    pub fn with_parallel_threshold(self, threshold: usize) -> Self {
188        self.jacobian_dispatch.set(threshold);
189        self
190    }
191
192    /// Reconfigures the same threshold at runtime, through `&self` — no
193    /// rebuild required. Scoped to this solver instance. Only exists when
194    /// the crate is built with the `parallel` feature.
195    ///
196    /// # Panics
197    ///
198    /// Panics when `threshold == 0` — see `ParallelThreshold::set`.
199    #[cfg(feature = "parallel")]
200    pub fn set_parallel_threshold(&self, threshold: usize) {
201        self.jacobian_dispatch.set(threshold);
202    }
203
204    /// Returns the effective dispatch threshold of the Jacobian assembly —
205    /// the override if one was set, otherwise an indicative default of 256
206    /// unknowns. The crossover depends on the model, and on the banded path
207    /// parallelism is limited to the 2b + 1 colors, which rarely pays below
208    /// about 10⁴ nodes: measure the target workload (see
209    /// [`crate::solver::parallel`]). Only exists when the crate is built
210    /// with the `parallel` feature.
211    #[cfg(feature = "parallel")]
212    pub fn parallel_threshold(&self) -> usize {
213        self.jacobian_dispatch.threshold()
214    }
215
216    /// Configures the sparse backend ([DA-043](https://github.com/biface/oxiflow/issues/103)), for the startup step and
217    /// the BDF2 update alike. Has no effect on its own — the banded path
218    /// also requires [`Self::with_jacobian_bandwidth`] and a system larger
219    /// than [`Self::with_sparse_threshold`] (default 100) at solve time;
220    /// otherwise the dense path is used unchanged.
221    #[cfg(feature = "sparse")]
222    pub fn with_sparse_solver(mut self, sparse_solver: Box<dyn SparseLinearSolver>) -> Self {
223        self.backend.sparse_solver = Some(sparse_solver);
224        self
225    }
226
227    /// Number of unknowns (nodes × components) above which the banded path
228    /// is used (default 100) — see [`Self::with_sparse_solver`].
229    #[cfg(feature = "sparse")]
230    pub fn with_sparse_threshold(mut self, sparse_threshold: usize) -> Self {
231        self.backend.sparse_threshold = sparse_threshold;
232        self
233    }
234
235    /// Declares the Jacobian's half-bandwidth (e.g.
236    /// `scheme.stencil_radius()`, [DA-039](https://github.com/biface/oxiflow/issues/95)) — see [`Self::with_sparse_solver`].
237    ///
238    /// Counted in flat unknowns. For a `ScalarField` state this is the
239    /// stencil half-width `s`; for a `VectorField` state of `d` components,
240    /// whose unknowns are interleaved by node, it is `d·(s + 1) − 1` ([#192](https://github.com/biface/oxiflow/issues/192)).
241    /// A band narrower than the Jacobian's leaves the Newton corrections
242    /// inexact: the step reports [`OxiflowError::NewtonNotConverged`]
243    /// rather than drifting from the dense path.
244    #[cfg(feature = "sparse")]
245    pub fn with_jacobian_bandwidth(mut self, jacobian_bandwidth: usize) -> Self {
246        self.backend.jacobian_bandwidth = Some(jacobian_bandwidth);
247        self
248    }
249}

251impl Solver for BDF2Solver {
252    fn solve(
253        &self,
254        scenario: &Scenario,
255        config: &SolverConfiguration,
256    ) -> Result<SimulationResult, OxiflowError> {
257        // `solve_fixed_step` (DD-034 follow-up) manages the history buffer
258        // generically via `self.history_depth()` -- exactly equivalent to
259        // the hand-written `history = vec![u]` this used to do, since
260        // `insert(0, prev); truncate(1)` is the same operation for a
261        // depth-1 buffer. No BDF2-specific loop needed any more.
262        self.solve_fixed_step(scenario, config)
263    }
264}
265
266impl SteppableSolver for BDF2Solver {
267    fn history_depth(&self) -> usize {
268        1
269    }
270
271    fn step(
272        &self,
273        domain: &Domain,
274        chain: &[&dyn ContextCalculator],
275        state: &mut ContextValue,
276        history: &[ContextValue],
277        t: f64,
278        dt: f64,
279    ) -> Result<ContextValue, OxiflowError> {
280        let formula = match history.first() {
281            // Startup (#44 acceptance criterion): no u^{n-1} yet -- bootstrap
282            // with one Backward Euler step to produce u^1 from u^0, under
283            // the solver's own Newton configuration.
284            None => ImplicitFormula::Theta(1.0),
285            Some(previous) => ImplicitFormula::Bdf2 { previous },
286        };
287        self.backend.step(
288            domain,
289            chain,
290            state,
291            t,
292            dt,
293            formula,
294            &self.newton,
295            &self.jacobian_dispatch,
296        )
297    }
298}

425    #[test]
426    fn exponential_decay_matches_recurrence_after_startup() {
427        // Independent reimplementation of the BDF2 recurrence (derived by
428        // hand, see module docs) -- cross-checks the solver's output
429        // rather than re-deriving the same formula from its own code.
430        let lambda = 2.0;
431        let dt = 0.1;
432        let n_steps: usize = 10;
433        let scenario = Scenario::single(Box::new(ExponentialDecay { lambda }), make_mesh(2));
434        let config = make_config(n_steps as f64 * dt, dt);
435        let result = BDF2Solver::new().solve(&scenario, &config).unwrap();
436
437        let mut u_prev = 1.0_f64; // u^0
438        let mut u_curr = u_prev / (1.0 + lambda * dt); // u^1, Backward Euler startup
439        for _ in 1..n_steps {
440            let u_next = (2.0 * u_curr - 0.5 * u_prev) / (1.5 + lambda * dt);
441            u_prev = u_curr;
442            u_curr = u_next;
443        }
444
445        let final_field = result.states.last().unwrap().as_scalar_field().unwrap();
446        for v in final_field.iter() {
447            assert!((v - u_curr).abs() < 1e-9, "got {v}, expected {u_curr}");
448        }
449    }

584    /// Backward Euler root of `u + dt*u^3 = u_prev`, solved by scalar
585    /// Newton independently of the crate's loop.
586    fn backward_euler_cubic_decay(u_prev: f64, dt: f64) -> f64 {
587        let mut u = u_prev;
588        for _ in 0..100 {
589            let g = u + dt * u.powi(3) - u_prev;
590            let dg = 1.0 + 3.0 * dt * u.powi(2);
591            u -= g / dg;
592        }
593        u
594    }
595
596    /// BDF2 root of `1.5*u + dt*u^3 = 2*u_n - 0.5*u_prev`, solved by scalar
597    /// Newton independently of the crate's loop.
598    fn bdf2_cubic_decay(u_n: f64, u_prev: f64, dt: f64) -> f64 {
599        let rhs = 2.0 * u_n - 0.5 * u_prev;
600        let mut u = u_n;
601        for _ in 0..100 {
602            let g = 1.5 * u + dt * u.powi(3) - rhs;
603            let dg = 1.5 + 3.0 * dt * u.powi(2);
604            u -= g / dg;
605        }
606        u
607    }

609    #[test]
610    fn full_newton_resolves_nonaffine_correction_beyond_frozen_jacobian() {
611        // f(u) = -u^3 -- genuinely nonlinear. `dt` is small enough for the
612        // default single correction to pass its tolerance at both steps,
613        // only approximately; FullNewton reaches the true discrete solution
614        // at both steps, the bootstrap step included (J7 exit criterion,
615        // #112).
616        let dt = 0.01;
617        let config = make_config(2.0 * dt, dt); // exactly two steps
618
619        let scenario_default = Scenario::single(Box::new(CubicDecay), make_mesh(2));
620        let default_result = BDF2Solver::new().solve(&scenario_default, &config).unwrap();
621
622        let scenario_full = Scenario::single(Box::new(CubicDecay), make_mesh(2));
623        let full_result = BDF2Solver::new()
624            .with_newton_convergence(NewtonConvergence::default())
625            .with_jacobian_strategy(JacobianStrategy::FullNewton)
626            .with_max_newton_iterations(50)
627            .solve(&scenario_full, &config)
628            .unwrap();
629
630        // u^1 comes from the Backward Euler bootstrap step, run with the
631        // solver's configuration.
632        let u0 = 1.0_f64;
633        let u1_reference = backward_euler_cubic_decay(u0, dt);
634        let u1_full = full_result.states[1].as_scalar_field().unwrap()[0];
635        assert!(
636            (u1_full - u1_reference).abs() < 1e-12,
637            "FullNewton should converge the bootstrap step: got {u1_full}, expected {u1_reference}"
638        );
639
640        // Independently solved BDF2 equation for the real second step:
641        // (3/2)*u2 - 2*u1 + (1/2)*u0 = dt*(-u2^3), i.e.
642        // 1.5*u2 + dt*u2^3 = 2*u1 - 0.5*u0, using the *actual* u1 of the
643        // FullNewton run, so this reference checks the second step alone.
644        let u2_scalar = bdf2_cubic_decay(u1_full, u0, dt);
645
646        let full_value = full_result.states[2].as_scalar_field().unwrap()[0];
647        let default_value = default_result.states[2].as_scalar_field().unwrap()[0];
648
649        assert!(
650            (full_value - u2_scalar).abs() < 1e-6,
651            "FullNewton should reach the converged discrete solution: got {full_value}, expected {u2_scalar}"
652        );
653        assert!(
654            (default_value - full_value).abs() > 1e-7,
655            "default single correction should measurably differ from the converged solution: \
656             default={default_value}, full={full_value}"
657        );
658    }

662        // At dt = 0.5, the Backward Euler bootstrap step of f(u) = -u^3

664        // tolerance: every budget below that must fail and report the

680
681        // A tolerance far below the default one: the bootstrap step only
682        // reaches the reference if it honours the configured criterion

704    /// Takes the banded path on every system: half-bandwidth 0 (the
705    /// Jacobians of these scalar models are diagonal), threshold 0, and a
706    /// sparse solver counting its calls in `sparse_calls`.
707    #[cfg(feature = "sparse")]
708    fn banded(solver: BDF2Solver, sparse_calls: &Arc<AtomicUsize>) -> BDF2Solver {
709        solver
710            .with_jacobian_bandwidth(0)
711            .with_sparse_threshold(0)
712            .with_sparse_solver(Box::new(CountingSparseSolver {
713                calls: Arc::clone(sparse_calls),
714            }))
715    }

719    fn banded_path_runs_the_bootstrap_step_and_the_bdf2_update() {
720        // Three steps, one correction each: the bootstrap step and both
721        // BDF2 updates solve the banded system, never the dense one, and
722        // give the results of the dense path.
723        let dt = 0.1;
724        let config = make_config(3.0 * dt, dt);
725        let model = || Box::new(ExponentialDecay { lambda: 3.0 });
726

728        let sparse_calls = Arc::new(AtomicUsize::new(0));
729        let solver = banded(
730            BDF2Solver::new().with_linear_solver(Box::new(CountingLinearSolver {
731                calls: Arc::clone(&dense_calls),
732            })),
733            &sparse_calls,
734        );

742            .solve(&Scenario::single(model(), make_mesh(4)), &config)
743            .unwrap();
744        // The systems are diagonal: both factorisations reduce to one
745        // division per unknown, and the states agree bit for bit (measured).
746        assert_eq!(banded_result.states, dense_result.states);
747    }
